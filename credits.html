Credits & licenses

The games on this site were made with PlayPrompt. Each game page is self-contained: it carries the game's code together with the open-source software, 3D models and sounds listed below. Thank you to their authors.

three.js

All 3D rendering uses three.js (release r187), embedded in each game page. Copyright © 2010-2026 three.js authors. Released under the MIT License, full text in licenses/three.js-MIT.txt. The copyright notice is also kept inside every game page.

3D models: Kenney

Games in the “model library” columns use 3D models from Kenney (www.kenney.nl), released under Creative Commons Zero (CC0 1.0). Credit is not required by the license; we give it gladly. Packs used by these games:

  • Car Kit, Castle Kit, City Kit (Roads), Cube Pets, Fantasy Town Kit, Graveyard Kit, Holiday Kit, Marble Kit
  • Mini Characters, Minigolf Kit, Nature Kit, Platformer Kit, Space Kit, Survival Kit, Tower Defense Kit, Watercraft Kit

Sound effects and jingles: Kenney

The interaction sounds and the short win and lose jingles come from Kenney's Interface Sounds, Digital Audio, Impact Sounds, RPG Audio and Music Jingles packs, all released under CC0 1.0. Full license text: licenses/CC0-1.0.txt.

Physics

PlayPrompt's own 2D physics engine, embedded in each page, follows algorithms described in the MIT-licensed book “Rust Game Development Physics Math” by Arpan Pathak, and Erin Catto's published sequential-impulse method.

Everything else

The game ideas were written by the PlayPrompt team. The games themselves, this site and PlayPrompt's own runtime libraries are © PlayPrompt.
